# FX M1 Signal — Android

Первая версия Android-приложения для ручного выбора популярного инструмента и технического анализа:

- M1 — вход;
- M5 / M15 / H1 — фильтр направления;
- BUY / SELL / WAIT;
- Entry / SL / TP1 / TP2;
- условная оценка силы сигнала;
- данные через Twelve Data.

## Встроенные инструменты

EUR/USD, GBP/USD, USD/JPY, USD/CHF, AUD/USD, USD/CAD, NZD/USD,
EUR/JPY, GBP/JPY, EUR/GBP, EUR/CHF, AUD/JPY, CAD/JPY, CHF/JPY,
GBP/CHF, EUR/AUD, GBP/AUD, AUD/NZD, NZD/JPY и XAU/USD.

## Как получить APK через GitHub

1. Создайте новый репозиторий GitHub.
2. Загрузите в него содержимое этой папки.
3. Откройте вкладку **Actions**.
4. Workflow **Build Android APK** запустится автоматически.
5. После успешной сборки откройте завершённый workflow.
6. Внизу страницы скачайте artifact **FX-M1-Signal-APK**.
7. Внутри будет `app-debug.apk`.

APK не требует Android Studio на вашем компьютере.

## API key

Приложение при первом запуске просит API key Twelve Data.
Ключ сохраняется только локально в настройках приложения.

## Важное ограничение v1

На один анализ приложение делает 4 запроса: M1, M5, M15, H1.
Поэтому бесплатный API-тариф может ограничивать частоту нажатий.
В следующей версии можно добавить серверный кэш, WebSocket и автоматическое обновление.

## Торговля

Версия 1 **не открывает сделки** и не имеет доступа к брокерскому счёту.
Сначала нужно проверить статистику сигналов на демо.
