# FX M1 Bot V7.4.0 — AUDITED FULL

Это полная чистая версия проекта после аудита 31.08.2026.

Ключевое:
- версия приложения берётся из BuildConfig.VERSION_NAME и больше не должна расходиться между шапкой/умными функциями/footer;
- статус системы показывает одновременно APP Vx и BRIDGE Vx;
- SCALP M1 имеет отдельный executionSignal и может исполнять micro BUY/SELL, даже если основной экран показывает WAIT;
- Bridge использует реальный MT5 Bid/Ask, нормализует SL/TP и перебирает поддерживаемые filling modes при retcode 10030;
- SCALP basket: до 10 позиций, по умолчанию 8, без мартингейла; добавления только по благоприятному движению и в рамках basket risk;
- REAL trading выключен по умолчанию; тестировать на DEMO.

## Запуск Bridge
Откройте MT5 DEMO и запустите `mt5_bridge/START_BRIDGE_V7_3.bat`. В консоли должно быть `FX M1 MT5 Bridge V7.4.0`.

## Проверка APK
После установки в блоке состояния должно одновременно отображаться `APP V7.4.0` и `BRIDGE V7.4.0`. Если номера отличаются, тест торговли не проводить.
