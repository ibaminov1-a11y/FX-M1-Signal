FX M1 BOT V6.1 — UX / PAUSE / JARVIS SETUP

1. TWELVE DATA API KEY
- Если ключ ещё не сохранён: поле и кнопка «СОХРАНИТЬ API KEY» видны.
- После сохранения поле с точками и подпись полностью скрываются.
- Остаётся только компактная кнопка «ИЗМЕНИТЬ API KEY».
- Нажатие «ИЗМЕНИТЬ API KEY» снова раскрывает поле.

2. МОНИТОРИНГ / ФОН
- Верхняя кнопка приложения: только обычный мониторинг.
- Фоновый режим: отдельный foreground service.
- В шторке:
  микрофон = JARVIS
  пауза = приостановить анализ, НО фон/уведомление остаётся
  play = продолжить анализ
  power = полностью выключить фоновый сервис
- Пауза больше не удаляет фоновое уведомление.

3. ТАЙМЕР СИГНАЛА
- Время «Открыт» сохраняется в едином state_*.
- Переключение источника MON/BG больше не должно сбрасывать таймер.
- UI обновляет «прошло» каждую секунду.
- Для WAIT таймера открытия нет, потому что WAIT не является открытым сигналом.

4. JARVIS
- Русский голос V6/V6.1 НЕ использует системное распознавание языка телефона.
- Для голоса нужен AI-сервер.
- Без адреса сервера JARVIS теперь показывает предупреждение только один раз, а не спамит одинаковыми строками.
- После успешной проверки адрес сервера сохраняется.
- Кнопка JARVIS в шторке запускает голосовой сервис без принудительного открытия Activity.

ВАЖНО ПО ТЕКУЩЕМУ СКРИНУ:
На вашем скрине JARVIS пишет «сначала укажите адрес AI-сервера».
Это означает, что APK уже перешёл на серверный русский STT/TTS, но backend ещё не запущен/не указан.
Без работающего backend JARVIS физически не сможет распознавать и говорить через OpenAI.
