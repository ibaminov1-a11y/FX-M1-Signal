# Установка EC1 R4 — Scenario Map и проверяемый разворот

APK: **10.9-EC1**, пакет Android **com.openai.fxm1.ec1**. Bridge: **10.9-EC1-R4-COMPUTE**, протокол **fxm1.event.v1**. Точный исходный commit и SHA-256 APK указаны в `PROVENANCE.json` внутри пакета.

## Обновление без потери состояния

1. На старом Bridge остановите новые входы через PAUSE. Дождитесь завершения собственной кампании EC1 либо явно закройте её и проверьте нулевые собственные позиции/ордера и закрытие в истории MT5. PAUSE сам по себе позиции не закрывает. Не заменяйте Bridge во время неизвестного или частичного исполнения.
2. Остановите старый процесс Bridge. Не запускайте два Bridge одновременно.
3. Сделайте резервную копию старой папки `Bridge/event_state` целиком, включая `campaign.sqlite3` и `bridge-token.txt`. Копируйте состояние после остановки процесса; не удаляйте базу для обхода RECOVERY.
4. Распакуйте новый комплект в отдельную папку. Перенесите свою сохранённую `event_state` в новую папку `Bridge`, чтобы сохранить историю и токен. Не переносите старые файлы Python поверх нового кода.
5. Запустите `Bridge/START_BRIDGE_V10_0.bat` из нового комплекта на Windows с установленным MT5. Требования перечислены в `requirements_event.txt`; чисто Python-зависимости включены в `_vendor`. Библиотека MetaTrader5 и работающий терминал требуются отдельно.
6. Установите новый APK поверх существующего EC1. Не удаляйте установленное приложение заранее. Старое приложение с пакетом `com.openai.fxm1` является отдельным продуктом; этот APK использует `com.openai.fxm1.ec1`.

## Перед AUTO

Используйте отдельный **USD DEMO hedging** счёт. Проверьте адрес компьютера, токен, соединение, свежесть котировки, фактические balance/equity, историю, комиссии и риск. После перезапуска Bridge AUTO выключен; незавершённое исполнение требует сверки.

Рабочий режим этой версии — **NORMAL / M5 / COMPUTE_V1**. Вход и сопровождение рассчитывает Bridge; телефон не принимает самостоятельных торговых решений. Информационное уведомление не содержит торговых кнопок. Управление выполняется из приложения; сворачивание приложения само по себе не выключает AUTO на Bridge.

## Что должно появиться

Слева — реальные свечи MT5. Справа — основной и противоположный альтернативный сценарий, уровни BUY/SELL и отмена активной позиции. В слабом рынке — уровни и WAIT, без выдуманной направленной траектории. Числа около сценариев — веса модели, а не измеренная вероятность успеха. Время пути условное.

При отмене BUY он закрывается независимо от готовности SELL. SELL допустим только после подтверждения своего входа, полного закрытия BUY и сверки истории. Если сигнал исчез, цена ушла слишком далеко, данные устарели или проверка заняла слишком много времени, новый ордер пропускается. Ошибка/неизвестный результат исполнения не означает, что позиция закрыта.

## Ограничения

Реальный адаптер MT5 в этой версии блокирует отправку на REAL/contest и на неторгуемый либо не-hedging счёт. Наличие старых полей REAL pilot в интерфейсе/метаданных не отменяет эту блокировку. При разработке реальные рыночные ордера не отправляются.

Не открывайте порт Bridge в Интернет и не публикуйте токен. Тесты с имитатором MT5 и Android-эмулятором не доказывают доходность, отсутствие проскальзывания или работу на конкретном физическом телефоне. Разворот без убытка не гарантируется.
