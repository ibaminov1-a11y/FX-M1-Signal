# Установка EC1 без удаления V10.8

EC1 — отдельное приложение «FX M1 EC1», пакет com.openai.fxm1.ec1. Оно устанавливается рядом с V10.8 и не стирает её настройки или локальный журнал. Перенос настроек между разными Android-пакетами автоматически не выполняется: в EC1 нужно указать адрес и новый ключ Bridge, режим, таймфрейм и известную комиссию. История счёта и Balance/Equity загружаются непосредственно из MT5.

Нельзя включать AUTO в двух версиях одновременно. Прежде чем запускать EC1, выключите AUTO и мониторинг V10.8 и остановите старый Bridge. Не удаляйте прежнюю версию, .venv, историю MT5 и резервную копию старого Bridge. Не переносите открытые позиции старого алгоритма в новый: EC1 ими не управляет.

Полный пакет содержит APK и папку Bridge. После резервного копирования старой mt5_bridge скопируйте в неё содержимое новой папки Bridge целиком, включая event_core и _vendor. Один файл bridge_v10_0.py недостаточен. Старое Python-окружение .venv сохраняется. Запуск прежним START_BRIDGE_V10_0.bat из этой папки. Launcher ничего не устанавливает автоматически. Чистые Python-зависимости Flask включены, а Windows-пакет MetaTrader5 используется из вашей .venv.

Оставьте MT5 на USD DEMO hedging. Скопируйте новый ключ из окна Bridge в «Ключ Bridge» приложения EC1, укажите адрес сервера. Сначала запустите мониторинг без AUTO. В «Умные функции → Настроить» проверьте параметры и известную комиссию (ноль только при достоверном отсутствии комиссии). AUTO включается отдельно с подтверждением профиля.

Действует отдельная база риска 100 USD, а на главной показывается настоящий баланс MT5. Исходный процент 0,25% при базе100 означает плановый бюджет0,25USD, дополнительно ограниченный абсолютным потолком0,50USD. Минимальный лот может не поместиться — тогда вход пропускается, а риск не повышается автоматически.

Это исследовательская DEMO-сборка с исполняемыми тестами, а не подтверждённо прибыльная стратегия. Проверка на реальных исторических тиках и на физическом Xiaomi пока не выполнена. REAL заблокирован. Все параметры стратегии и ограничения описаны в READ_ME_RU.md.
