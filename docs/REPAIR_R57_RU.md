# Восстановление запуска Bridge R5.7

Для ошибки `ImportError: cannot import name 'VERSION' from 'event_core'`.

## Как запустить

1. Закройте окно Bridge. Если он всё же работает в другом окне, сначала остановите AUTO и завершите текущую серию перед заменой файлов.
2. Скопируйте только `REPAIR_BRIDGE_R57.cmd` в действующую папку Bridge, рядом с `START_BRIDGE_V10_0.bat` и `bridge_v10_0.py`. На присланном скриншоте это `C:\Users\Hp\OneDrive\Documents\GitHub\FX-M1-Signal\mt5_bridge`.
3. Запустите `REPAIR_BRIDGE_R57.cmd` двойным щелчком и нажмите любую клавишу для начала. Дождитесь строк `OK: 10.9-EC1-R5.7 installed` и `SERVER_IMPORT_OK`.
4. Запустите `START_BRIDGE_V10_0.bat` из этой же папки. В заголовке запуска должна быть версия `10.9-EC1-R5.7`.

APK R5.7, если он уже установлен, переустанавливать не требуется.
Не копируйте содержимое `event_core/scenarios` в `event_core`: оба каталога содержат разные файлы с именем `__init__.py`.
При `INSTALL FAILED` не продолжайте установку вручную: сохраните текст или скриншот всего окна с первой ошибкой.

## Что делает восстановление

Файл содержит весь программный комплект Bridge R5.7. Проверяет контрольные суммы и синтаксис, загружает сервер и точку входа во временной папке, сохраняет старые файлы в `bridge_program_backup_...`, заменяет программу и повторяет проверку. Если проверка после замены не проходит, восстанавливает старую программу.

Торговая база `event_state`, ключ подключения, часы брокера, настройки исследования и `.venv` сохраняются. Старый кеш Python остаётся в резервной копии. Восстановление не подключается к MT5 и не отправляет торговые команды.

## Что установлено по ошибке

На скриншоте сервер загрузил `event_core/__init__.py`, но не нашёл `VERSION`. В исходном выданном ZIP переменная присутствует. По одному скриншоту нельзя установить, почему запущенная копия отличается: для этого нужен именно её файл. Поэтому восстановление заменяет весь комплект модулей, сохраняя прежнюю копию для разбора.

В прежнем установщике было недостаточно проверки одного `BUILD`; проверка реального импорта сервера добавлена в эту версию установщика. Торговая логика и APK совпадают с выданной R5.7. Результаты выполнения на Windows находятся в `Verification/WINDOWS_REPAIR_RESULTS.json` и логах рядом. Проверка `--help` загружает точку входа, но не проверяет подключение к живому терминалу MT5.
