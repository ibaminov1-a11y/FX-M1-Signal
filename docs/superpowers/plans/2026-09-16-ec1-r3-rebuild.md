# EC1 R3 Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild M5 entry logic from clean EC1 R2.5 so EventCore can enter a confirmed live impulse before M5 closes, enter a shallow trend continuation without waiting for a deep pullback, and retain the classic pullback path without a 40-minute dead period.

**Architecture:** Keep R2.5 execution, risk, reconciliation, Emergency, DEMO-only and AUTO ownership unchanged. Add independent M1/M5/M15/H1 market layers, a non-repainting M5 swing map, and three deterministic entry detectors (`IMPULSE`, `CONTINUATION`, `PULLBACK`) inside Bridge/EventCore; Android only renders Bridge state and real MT5 candles/levels.

**Tech Stack:** Python 3.12, Flask/EventCore, MetaTrader5 adapter, `unittest`, Java Android API 35, Gradle 8.9, Android instrumentation tests, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-16-ec1-r3-rebuild-design.md`

## Global Constraints

- Baseline is clean R2.5 commit `bc3cef9322685c290f3e88c17f08212bb72d6c4a` on branch `feature/ec1-r3-rebuild`.
- Do not copy implementation code from the abandoned R3 attempt.
- No self-modifying CI or `apply.py`; CI must be read-only with respect to repository contents.
- Trading authority stays in Bridge/EventCore; Android cannot generate BUY/SELL decisions.
- USD DEMO hedging only; REAL remains blocked.
- Preserve R2.5 `_entry()`, campaign risk, broker-SL checks, margin checks, unknown-execution recovery, duplicate-event protection, manual/V10 isolation, Emergency persistence, and background AUTO behavior unless a failing regression test proves a required change.
- M5 R3 inputs are: closed M1, closed M5, closed M15, closed H1, current forming M5, and current tick.
- Still-forming M5 is never mixed into confirmed swing calculations.
- `IMPULSE`: M5 body >= `0.70 ATR`, range >= `1.00 ATR`, body/range >= `0.65`, confirmed swing break, last closed M1 beyond break, live tick beyond break, H1/M15 not opposite, no-chase and all execution/risk checks pass.
- `CONTINUATION`: confirmed M5 trend, shallow retrace `0.10 <= retrace < 0.35 ATR`, at least one opposing/neutral micro-leg, fresh local continuation break confirmed by M1 and tick, H1/M15 not opposite.
- `PULLBACK`: classic retrace `>= 0.35 ATR` plus fresh trigger.
- NORMAL pending setup lifetime is `3` M5 bars = `15 minutes`; no 40-minute dead period.
- Same-direction live IMPULSE/CONTINUATION may supersede a pending PULLBACK.
- Additions remain same-direction, event-driven, campaign-net-positive, price-progress gated and campaign-budget limited; no strategy cap of 10.
- Android chart never draws a fake future-price projection.
- Release requires Python + Android build + emulator + packaging from one exact commit SHA.

```python
    timeframe=getattr(self.mt5,'TIMEFRAME_'+tf,None)

    x=rows[-1]
    return Bar(int(x['time']),float(x['open']),float(x['high']),float(x['low']),float(x['close']),float(x['tick_volume']))
```

```python
def swing_labels(bars):
    pts=pivots(bars)
    last_high=None; last_low=None; out=[]
    for p in pts:
        label=p['kind']
        if p['kind']=='H':
            label='H' if last_high is None else ('HH' if p['price']>last_high else 'LH')
            last_high=p['price']
        else:
            label='L' if last_low is None else ('HL' if p['price']>last_low else 'LL')
            last_low=p['price']
        out.append({**p,'label':label})
    return tuple(out)

def context_direction(bars):
    return direction(pivots(bars))
```

- [ ] **Step 4: Implement `_impulse_decision`**

Algorithm:
1. Require `timeframe == 'M5'`, `live_bar`, at least 32 closed M5, 2 M1, and valid M15/H1 context.
2. Compute M5 ATR from closed bars only.
3. Determine candidate side from live candle body sign.
4. Reject if body, range or body/range thresholds fail.

6. Require live close/tick and last closed M1 close beyond the padded break level.

8. Reject chase distance `abs(q.bid-trigger) > profile.no_chase_atr*a`.
9. Build stable event id; if consumed return WAIT.
10. Return `Decision(... phase='ENTRY_READY', path='IMPULSE', structure=swing_labels(bars))`.
