# R7.3 runtime and native release gates

The exact-source native results and counts are generated by CI in `Verification/` and `PROVENANCE.json`. This document describes the repaired boundaries and the required release gates; it does not substitute for their results.

## Reproduced baseline

Two Android API35 runs compile the new UI regressions against unchanged R7.2 production:

- https://github.com/ibaminov1-a11y/FX-M1-Signal/actions/runs/37268092817 — original 20 tests, 17 failures.
- https://github.com/ibaminov1-a11y/FX-M1-Signal/actions/runs/37268792244 — expanded 26 tests; reproduces timeframe/symbol/stale publication, WAIT width and actual-position overlay defects as well.

The baseline tests fail on behavioral assertions, not a compilation failure. New APIs for durable command envelopes are verified in R7.3, rather than being transplanted into R7.2 where those APIs do not exist.

## Bridge boundary

- `/ec/state` and `/health` remain responsive from an immutable, profile-specific publication while the serialized MT5 owner is busy. No MT5 calls run from a normal state snapshot.
- Publication age, quote freshness, account age, history freshness and position age expire independently of a successful HTTP response. Cached data do not authorize an entry.
- Commands waiting over 250 ms for admission receive HTTP503 with `accepted=false`; they are not queued to execute after the client has abandoned them. An accepted durable Emergency retains its command identity when the phone retries.
- Account-wide position snapshots are bound to the MT5 account key. Account adoption cannot relabel the previous account's positions. Positions remain unavailable until freshly confirmed.
- Lost MT5 IPC clears the adapter initialization state so the next read can reconnect. Initialization uses the documented positional terminal path and a bounded 5000 ms timeout.
- Runtime exceptions publish the inhibited AUTO/recovery state. Rotating runtime diagnostics redact the Bridge key, including exception text.

## Required native release checks

- Entire Python regression suite; real Flask/Portfolio integration with substituted broker transport, risk/campaign recovery and explicit partial-close history tests.
- All current EventCore Android instrumentation classes on Android API35. The retired `V108RepairTest` targets version10.8/TwelveData and is excluded explicitly; it is not part of the current EventCore protocol.
- Charts: actual PNG captures at multiple widths for EURUSD, USDJPY, XAUUSD and BTCUSD; all frame scales; history/archive/offline/stale labels; two scenarios; actual broker Entry/SL distinct from hypotheses.
- Native Windows CMD: existing mixed installation, locked state, WAL preservation, rollback, Unicode/spaces/exclamation marks, private fresh virtual environment, installed launcher check and read-only diagnostics.
- Source commit, APK, versionCode931 and original certificate fingerprint must match. Packaging fails without the required passing result files and chart screenshots.

## Evidence limits

Broker transport is substituted in automated trading tests. API35 is a real emulator, not the user's physical phone. Native Windows tests exercise installation and imports, not an authenticated broker terminal. User LAN/firewall/VPN routing, terminal responsiveness and broker fills must still be observed on the user's installation. No automatic test proves forecast accuracy or profitability. DEMO-only enforcement remains intact.
