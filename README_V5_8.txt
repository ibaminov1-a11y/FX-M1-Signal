FX M1 Bot V5.8

1) МОНИТОРИНГ и ФОН теперь независимы.
   - Верхняя кнопка: только мониторинг в открытом приложении.
   - Кнопка ФОН: только foreground service.
   - Выключение одного не выключает другой.
   - Если оба включены, фон является источником данных, чтобы не расходовать API дважды.

2) JARVIS:
   - Добавлена кнопка ГОЛОС / MUTED.
   - MUTED сразу останавливает локальный TTS и серверное аудио.
   - Фон больше не включается автоматически при запуске JARVIS.

3) Уведомление фона:
   - JARVIS: открыть ассистента.
   - ФОН OFF: выключить только фон.
   - STOP ALL: выключить фон, AUTO и запросить остановку обычного мониторинга.

4) Русская речь:
   - Системный SpeechRecognizer телефона всё ещё зависит от установленного русского языка.
   - Надёжное русское распознавание и голос нужно перевести на серверный STT/TTS.
